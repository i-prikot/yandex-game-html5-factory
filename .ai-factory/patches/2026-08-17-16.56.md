# Configurable nonstandard Docker host port

**Date:** 2026-08-17 16:56
**Files:** docker-compose.yml, .env.example, README.md
**Severity:** low

## Problem

Docker Compose could not start the `factory` service because its fixed host
binding `0.0.0.0:5173` was already allocated.

## Root Cause

The compose file used the Vite development port for both the container and the
host. The host port was fixed, so another local Vite process prevented the
container from starting.

## Solution

Changed the mapping to `${FACTORY_HOST_PORT:-15173}:5173`. Vite keeps its
expected internal port while Docker exposes it on the nonstandard host port
`15173` by default. The value is documented and can be changed in `.env`.

## Prevention

- Treat container and host ports as separate configuration concerns.
- Make host port bindings configurable when they can clash with local tooling.
- Validate Compose interpolation with `docker compose config --quiet` after
  changing service networking.
